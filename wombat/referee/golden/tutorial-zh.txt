    单元格格式和缩放
      (14) 单元格中的文本类似于一个单独的段落。它根据其所在列的列宽自动换行。列宽应该根据你如何偏好整体结构你的 TreeSheet 来确定。你可以通过状态栏看到列宽（鼠标所在的列）。确保这个单元格被选中，然后按住 ALT 并滚动鼠标滚轮看看会发生什么（或 ALT+PGUP/PGDN）。这个单元格应该自动重新格式化，以及这个列中的其他单元格，以及此列中的任何网格。注意，列宽指定的是每行的最大字符数，所以一旦每个单元格都在单独的一行上，它就不会使网格变宽。
        在某些 Mac 键盘上，PGUP/PGDN 使用 FN+UP/DOWN 模拟。另外，触控板（或魔术鼠标）上的滚轮是滑动手势。
      (15) 更强大的选项是改变单元格在屏幕上占用的空间（有助于指示某些事物的相对重要性），那就是改变文本大小。选择这个单元格，按住 SHIFT 并滚动鼠标滚轮（或 SHIFT+PGUP/PGDN）。
      (16) 注意，如果你持续缩小，最终文本将被渲染为单个像素。这可能看起来没用，但实际上是一种整洁的信息管理方式，取代了其他应用程序中常见的层次结构的折叠/展开。
      (17) 例如，这个单元格包含一个小网格。选择这个单元格，然后按住 CTRL 并向前滚动鼠标滚轮 3 次来放大这个单元格（或 CTRL+PGUP/PGDN）。
        (18) 你之前看不到这段文字，但现在可以了！
        (19) 当你放大时，TreeSheets 将基础文本大小设置为显示的最顶层网格的平均大小。当你使用 SHIFT+滚轮来改变文本大小时，你改变的是文本的相对大小。这意味着文本看起来有多大取决于缩放级别。这可能听起来有些复杂，但实际上，你可以让文本变得非常小，但当你放大时仍然可以看到更多。
        (20) 这个想法是，你使用像这样的小网格来存储信息（例如特定项目的待办事项列表），你希望它在你的整体 TreeSheet 中可用，但你不希望它占用空间。阅读或编辑它总是鼠标滚轮一转的事情。
        (21) 此外，设置文本大小通常只需要做一次，而你在其他应用程序中最终要做的树状折叠/展开或滚动是你每次想要查看信息时都要做的事情。TreeSheets 使得浏览大量信息变得不那么繁琐，更容易概览（像素大小的文本仍然给人留下了单元格内包含的信息量和结构的印象）。
        (22) 要让这段文本在顶层再次可读，请选择单元格（18..23）（不是 17），缩小两次（向后滚动鼠标滚轮），然后使用 SHIFT+鼠标滚轮向前，直到再次可读。
        (23) 如果现在你想让这个变得更小，选择相同的单元格，并使用 SHIFT+鼠标滚轮向后减小大小。
        (24) 注意到当你放大时，你在标题文本上方看到的灰色文本吗？这被称为上下文，可以帮助你记住你放大的树表的哪一部分。
      如果你更倾向于完全将一个网格隐藏起来，你可以使用折叠功能（在 Windows 上按 F10，在其他平台上按 CTRL+F10）。试着在这个单元格上重复按它来查看效果。
        这个单元格和下面的单元格将被隐藏！
        注意，拥有折叠网格的单元格会获得一个 '+' 图标作为它的图像，表示有额外的信息可以显示。如果你展开它，图像将自动消失。
        如果你使用诸如“搜索下一个”之类的功能跳转到当前不可见的单元格，单元格也会自动展开。
        尽管折叠可能是你在其他应用程序中熟悉的操作，但缩小文本（见 17）将给你更好的信息概览，试试看！

    图像 样式
      将图像添加到单元格中，使您的文档更清晰。图像会出现在该单元格文本的前面。将图像放在自己的单元格中以获得最大的灵活性。尝试在上述任何单元格中添加（小）图像（菜单编辑/添加图像，或从工具栏上的图像下拉菜单中选择一个）。 
        图像存储在文档（.cts）文件中，这意味着如果您移动文件，您将永远不会丢失图像。如果您在文档中多次使用图像，只存储一个副本。
        如果你想在树表中引用较大的图像，而且它们在表格中太笨重，你也可以简单地将图像放在 .cts 相同的文件夹中，并在单元格中只放置它们的名称。然后，你可以使用编辑/打开文件（F4）来查看它们。
          你可以用这种方式引用任何文件类型
          要方便地添加新文件链接，只需将非图像文件拖放到单元格上
      使单元格变粗，或斜体，或两者兼有！尝试在一些单元格上使用 CTRL+b 或 CTRL+i，两者都是切换。此外，打字机和下划线样式也可以从编辑/文本样式菜单中获得。
      删除线（CTRL+t）是 TODO 列表中的一种有用样式，用来表示已经处理过的项目，但你还不想删除。
      尝试使用工具栏中的两个颜色选择器给单元格上色。你可以双击当前颜色立即设置它们。选择包含网格的单元格，并使用边框颜色下拉菜单，或编辑/设置边框宽度菜单来改变它们的外观。
      可以为单元格添加备注，用来记录不想塞进其文本里的内容，例如细节、来源或提醒：选择单元格并按 CTRL+E（编辑(E) > 编辑备注(N)）。有备注的单元格会在右上角显示一个小三角形。将鼠标指向三角形即可阅读备注，单击它即可编辑备注。这个单元格就有备注，试试看！通过 视图(V) > 筛选 > 显示有备注的单元格 可以找到所有带备注的单元格。
    搜索 导航

    标签 层级
      标签是处理在表格中重复使用的单词的好方法，比如状态、类别等。要使某个词成为标签，找到一个出现，然后执行“添加单元格为标签”（编辑/标签... 菜单）。从现在开始，您可以将任何其他单元格设置为标签，使用 CTRL+右键鼠标（弹出菜单）。标签是蓝色的，以向您发出信号它是一个标签。这有助于发现标签是否拼写错误。
      与标签配合使用的一个强大操作是“层级交换”。一个例子说明它的作用：
        层级交换背后的动机是您使用 TreeSheets 以树形格式组织您的数据，但通常，树并不是组织数据的理想方式，因为它们迫使您做出关于哪个子分区最重要的选择。
        比如说，我正在组织一个项目，并试图追踪它涉及的任务。我使用标签来指示参与的人员、可交付成果和主题领域：

                set up networking

        实际上你所做的就是: “让我从 Fred 的角度看看这些信息”。现在你可以清楚地看到他在做什么。如果需要的话，你也可以为 Bob 做同样的事。如果你想看看 Fred 在后端做了什么，在“后端”按 F8一次(在 fred 中) ，你就又一次调整了你的视角。再按一次，现在前/后端成为主要的细分。
        继续按 F8 在各种标签上，看看你如何获得任何你需要的视角。
        重要的是要注意，在任何交换中，之前是父标签的，现在变成了所选标签的子标签。这意味着无论你有多少次这样做，都不会丢失信息。这意味着如果你愿意，你应该能够将树恢复到原始配置。
        所以你可以看到这个特性允许你拥有可以与任何数量的标签关联的信息片段。层级交换允许你确定当前标签的重要性顺序，因此，树视图只不过是最近的观点。
        你仍然可以在这个树的任何“视图”中编辑数据，不需要将树重置为原始顺序。像这样的树没有固定的顺序！
        注意，提升“Fred”并不自动提升“Bob”。TreeSheets 不知道这些标签是同一“类型”。并非所有标签的使用都有明确定义的类型，并不总是需要一次性重新排序，所以这使得功能保持简单。

      公式像电子表格一样计算结果，并且每当您更改内容时都会自动更新。在单元格中输入以 = 开头的文本，例如 =SUM(费用)，离开该单元格后它就会显示结果。公式栏（工具栏中的“Formula”）显示所选单元格的公式，您也可以在那里编辑它（按 ENTER 应用）。

        您可以使用 SUM、MIN、MAX、AVG、MEDIAN 和 COUNT，并结合数字、+ - * / 和括号，例如 =(SUM(收入) - SUM(费用)) / 12。只计算直接位于该命名网格中的数字，其他公式的结果也算作数字。在前面加上 TREE，例如 =TREESUM(费用)，所有子网格中的数字也会计算在内，但其中的公式不算。单独使用名称时，它表示其网格中唯一的那个数字，例如 =单价 * 数量。

        出现问题时，单元格会显示错误：#NAME? 表示未知的名称或函数，#DIV/0! 表示除以零，#CYCLE! 表示相互依赖的公式，#VALUE! 表示单独使用的名称或 SUBSET 中不是恰好一个数字，#N/A 表示程序运行之前的变量，#ERROR! 表示无法读取的公式。
      模板可以让您从事先准备好的文档开始新文档，例如每周计划或项目大纲。它们位于 文件 > 从模板新建：
        “将当前文档添加为模板”会把当前文档的文件添加到该菜单（请先保存），“将文件添加为模板...”会添加其他 TreeSheets 文件。
        点击其中的模板会创建一个新的未命名文档，内容是该模板的副本。模板文件本身保持不变，因为保存时会要求输入新的文件名。
        “将文件作为模板打开...”对任意 TreeSheets 文件执行同样的操作，但不会把它添加到菜单；“移除模板...”会把模板从菜单中移除（文件本身仍留在原处）。
      如果您在多台计算机上处理 TreeSheets 文件，请将它们存储在共享文件夹中（例如 Dropbox），并打开选项 -> 自动重新加载文档。
        这样，当您保存文档时，您将在所有机器上始终保持最新。
      从命令行运行 TreeSheets
        您可以从命令行运行 TreeSheets。
        作为参数，您可以指定一个要加载的单个文件。
          如果 TreeSheets 已经在系统中运行，这将导致它将文件传递给现有实例，然后退出。
        您也可以使用 -p 作为参数运行它。
          这将以“便携式”模式启动 TreeSheets，其中（在 Windows 上）它将设置写入当前目录的 .ini 文件中，而不是写入注册表。
        注意，为了能够正确地从命令行运行，至少在 Windows 上，需要使用完整路径启动 TreeSheets.exe，否则它将无法找到相对于可执行文件路径的图标等。
