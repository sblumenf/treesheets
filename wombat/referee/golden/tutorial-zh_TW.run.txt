   
  歡迎使用 TreeSheets！
  （1）這是一份可直接操作的教學檔。只要依照文字前面的編號逐步操作，就能快速、輕鬆學會 TreeSheets 的各項功能！
    基礎操作
      （2）找到第 2 步了！很好，現在來試著輸入文字。這些文字框每一個都稱為「儲存格」。看到（2）和（3）之間的空白儲存格了嗎？請點選其中任一位置來選取它 
      
      （3）上方的儲存格應該已選取，周圍會有粗黑框線。現在輸入一些內容，文字會進入已選取的儲存格。注意開始輸入時會出現游標，選取框也會變細；這表示儲存格已進入文字編輯模式，因此方向鍵、Delete 等操作會作用在目前文字上。也可以按兩下或按 Enter 進入文字編輯模式。若要離開，請再按一次 Enter、按 Esc，或直接選取另一個儲存格。
      （4）不過，插入文字還有更好的方式。看到儲存格之間的虛線了嗎？我們稱它們為「網格線」。請選取，也就是點選（4）和（5）之間的網格線
      （5）上方這條線應該已反白顯示。現在再開始輸入文字，會看到新的儲存格自動插入在（4）和（5）之間。儲存格的外框也能用同樣方式操作。這是延伸任何 TreeSheet 最自然的方式：找到想新增資訊的位置，直接開始輸入即可！
      （6）也可以不用滑鼠，在網格線與儲存格之間移動，以便更快編輯：請確認已選取這個儲存格，然後按幾次向上、向下方向鍵。
      （7）刪除儲存格的方式也一樣。請確認上方任一網格線已選取，接著按 Backspace 鍵移除它上方（或前方）的儲存格，或按 Delete 鍵移除它下方（或後方）的儲存格。這和文字編輯器、文書處理器的操作邏輯類似。也可以直接點選或拖曳選取任意儲存格，再按 Delete 鍵一次移除。
      （8）如果剛才刪掉了上方好幾列（希望不是這一列！），現在正好試試復原。連續按 Ctrl + Z 可復原剛才刪掉的內容。TreeSheets 提供不限次數的復原，所以按住 Ctrl + Z 一段時間，就能把文件還原到原始狀態。Ctrl + Y 則會重做。
        在 macOS 上，本教學提到 Ctrl 的地方請改用 Command。Alt 則相當於 Option 鍵。
    網格
      （9）應該已經注意到，TreeSheets 可以在儲存格中巢狀放入網格。每個儲存格都能包含自己的網格。例如這個儲存格就有一個子網格。

      （10）若要將網格加入任一儲存格，請選取該儲存格並按 Insert 或 Shift + Enter。請在這個儲存格試試看，文字下方應該會出現一個 1x1 網格
      （11）請試著延伸在（10）建立的儲存格：選取它四條網格線之一並輸入文字，直到至少形成 3x3 網格。也可以試著用方向鍵往各方向移動。
      （12）現在來試著在網格中移動內容。請在某個網格中選取整欄，例如（9）中包含數字的那個網格：從該欄最上方儲存格一路拖曳到最下方。就像試算表一樣，也和部分應用程式不同，TreeSheets 中的拖曳用來擴大選取範圍，而不是移動內容。現在按 Ctrl + 左方向鍵或 Ctrl + 右方向鍵，將資料左右移動。
      （13）也可以複製儲存格。例如選取這個儲存格，按 Ctrl + C 複製，接著選取上方任一網格線並按 Ctrl + V。如果選取多個儲存格，貼到目的地時會以多列插入。請試試看。剪下（Ctrl + X）或刪除多個儲存格選取範圍也同樣直覺。如果不想在貼上時把儲存格「插入同一層」，可以先建立新的網格，再貼到該網格中，以建立階層。
    儲存格格式與縮放
      （14）儲存格中的文字類似單一段落，會依所在欄的欄寬自動換行。欄寬要多寬，取決於整體 TreeSheet 想怎麼安排。狀態列會顯示滑鼠所在欄的欄寬。請選取這個儲存格，然後按住 Alt 並捲動滑鼠滾輪（或按 Alt + PgUp/PgDn），看看會發生什麼事。這個儲存格會自動重新排版，同一欄的其他儲存格，以及此欄內的任何網格也會一起調整。請注意，欄寬指定的是每行最多字元數；一旦每個儲存格都已在單行內顯示，它不會再讓網格變得更寬。
        有些 Mac 鍵盤會用 Fn + 向上/向下鍵模擬 PgUp/PgDn。另外，滑鼠滾輪在觸控板或 Magic Mouse 上則是滑動手勢。
      （15）若要更有力地改變儲存格在畫面上占用的空間，也就是表達某些內容相對重要性時，很適合調整文字大小。請選取這個儲存格，按住 Shift 並捲動滑鼠滾輪（或按 Shift + PgUp/PgDn）。
      （16）注意，如果持續縮小，文字最後會繪製成一個個像素。這看似沒用，其實是一種俐落的資訊管理方式，可取代其他應用程式常見的階層摺疊/展開。
      （17）例如這個儲存格包含一個很小的網格。請選取這個儲存格，然後按住 Ctrl 並向前捲動滑鼠滾輪 3 次，縮放進這個儲存格（或按 Ctrl + PgUp/PgDn）。
        （18）之前看不清楚這段文字，現在看得到了！
        （19）縮放進來時，TreeSheets 會把基準文字大小設定為目前顯示的最上層網格平均大小。用 Shift + 滑鼠滾輪調整文字大小時，調整的是文字的相對大小。也就是說，文字看起來有多大會受縮放層級影響。這聽起來可能有點複雜，但實際效果是：可以把文字縮得很小，縮放進來後仍能看到更多內容。
        （20）概念是使用像這樣的小型子網格儲存資訊，例如特定專案的待辦清單。這些資訊會保留在整體 TreeSheet 中，但不需要占用太多空間。只要動一下滑鼠滾輪，就能閱讀或編輯。
        （21）另外，文字大小通常只需要設定一次；相較之下，在其他應用程式中摺疊/展開樹狀結構或捲動，往往每次查看資訊都要做。TreeSheets 讓大量資訊的瀏覽不再那麼費力，也更容易掌握整體概況；像素大小的文字仍會讓人感覺到儲存格中包含多少資訊，以及其結構如何。
        （22）若要讓這段文字在最上層再次可讀，請選取儲存格（18..23）（不是 17），縮小兩次（向後捲動滑鼠滾輪），再用 Shift + 滑鼠滾輪向前捲動，直到這段文字再次可讀。
        （23）如果現在想把這些文字縮小，請選取相同的儲存格，並用 Shift + 滑鼠滾輪向後捲動來縮小。
        （24）縮放進來時，標題文字上方會看到灰色文字，注意到了嗎？這稱為脈絡，可幫助記住目前縮放進 TreeSheet 的哪個部分。
      如果想完全將網格藏起來，也可以使用摺疊（Windows 上按 F10，其他平台按 Ctrl + F10）。請在這個儲存格上重複按幾次，看看效果如何
        這個儲存格以及下方儲存格會被隱藏！
        請注意，擁有已摺疊網格的儲存格會出現「+」圖示作為圖片，表示還有可顯示的額外資訊。展開後，該圖片會自動消失
        如果使用「尋找下一個」等功能在目前不可見的儲存格之間跳轉，儲存格也會自動展開。
        摺疊可能是其他應用程式中熟悉的操作，但將文字縮到很小（見 17）通常能更清楚掌握資訊全貌，請試試看！

    圖片與樣式
      將圖片加入儲存格，可讓文件更清楚。圖片會出現在該儲存格文字前方。若要取得最大彈性，請把圖片放在自己的儲存格中。請試著將一張小圖片加入上方任一儲存格（選單 [編輯] > [新增圖片]，或從工具列的圖片下拉選單選取）。 
        圖片會儲存在文件（.cts）檔案內，代表即使移動檔案，也不會遺失圖片。如果同一張圖片在文件中使用多次，只會儲存一份。
        如果想在 TreeSheet 中參照大型圖片，但直接放進工作表會太笨重，也可以把圖片放在與 .cts 檔相同的資料夾，並在儲存格中只填入圖片檔名。接著可用 [編輯] > [開啟檔案]（F4）開啟檢視。
          任何檔案類型都可以用這種方式參照
          若要方便加入新的檔案連結，只要把非圖片檔案拖放到儲存格上即可
      可以把儲存格設成粗體、斜體，或兩者皆是！請在某些儲存格上試試 Ctrl + B 或 Ctrl + I，兩者都是切換式操作。另外，也可從 [編輯] > [文字樣式] 選單使用等寬字與底線樣式。
      刪除線（Ctrl + T）很適合用在待辦清單中，表示事項已處理但暫時不想刪除。
      請試著用工具列上的兩個色彩選擇器為儲存格上色。也可以在目前色彩上按兩下，立即套用。選取包含網格的儲存格後，可使用框線色彩下拉選單，或 [編輯] > [設定網格框線寬度] 選單來調整外觀。
      可以為儲存格加上備註，用來記錄不想放進其文字裡的內容，例如細節、來源或提醒：選取儲存格並按 CTRL+E（編輯(E) > 編輯備註(N)）。有備註的儲存格會在右上角顯示一個小三角形。將滑鼠指向三角形即可閱讀備註，按一下即可編輯備註。這個儲存格就有備註，試試看！透過 檢視(V) > 篩選 > 顯示含備註的儲存格 可以找到所有含備註的儲存格。

    標籤與階層
      標籤很適合處理工作表中反覆出現的詞，例如狀態、分類等。若要將某個詞設為標籤，請找到其中一次出現的位置，並執行「將儲存格內容加為標籤」（[編輯] > [標籤] 選單）。之後可用 Ctrl + 滑鼠右鍵（快顯選單）將任何其他儲存格設為標籤。標籤會以藍色顯示，提醒這是標籤，也有助於發現標籤是否拼錯。

        持續在不同標籤上按 F8，看看如何取得需要的任何視角。
        每次交換時，先前的父層級標籤會移到選取標籤底下，成為它的子層級。這表示無論交換多少次，都不會遺失資訊。也就是說，如果想要，應該能把樹狀結構恢復成原本的安排。
        因此，可以把這項功能視為：讓資訊片段能關聯任意數量的標籤。階層交換可決定標籤目前的重要性順序，所以樹狀檢視其實只是最近一次選擇出的檢視方式
        無論樹狀結構目前處於哪一種「檢視」，仍可繼續編輯其中資料，不需要先把樹狀結構重設回原本順序。這類樹狀結構沒有固定順序！
        請注意，提升「Fred」並不會自動提升「Bob」。TreeSheets 不知道這些標籤屬於相同的「類型」。不是所有標籤用途都有清楚類型，也不一定需要一次全部重新排序，因此這項功能保持簡單。

      範本可以讓您從事先準備好的文件開始新文件，例如每週計畫或專案大綱。它們位於 [檔案] > [從範本新增]：
        [將目前文件加入為範本]會把目前文件的檔案加入該選單（請先儲存），[將檔案加入為範本...]會加入其他 TreeSheets 檔案。
        點選其中的範本會建立一個新的未命名文件，內容是該範本的複本。範本檔案本身保持不變，因為儲存時會要求輸入新的檔名。
        [將檔案作為範本開啟...]對任意 TreeSheets 檔案執行相同的操作，但不會把它加入選單；[移除範本...]會把範本從選單中移除（檔案本身仍留在原處）。
      如果會在多台電腦上處理 TreeSheets 檔案，請把檔案存放在共用資料夾（例如 Dropbox）並開啟 [選項] > [自動重新載入文件]
        如此一來，儲存文件後，各台電腦上的內容都會保持最新。
