    セルの書式設定とズーム
      (14) セル内のテキストは1つの段落のようなものです。含まれている列の幅に応じて、自動的に複数行に分割されます。列の幅をどのくらいにするかは、TreeSheet全体をどのように構成したいかによって決めてください。ステータスバーには(マウスが乗っている列の)列幅が表示されます。このセルを選択した状態でALTキーを押しながらマウスホイールを回してみてください(またはALT+PageUp/PageDown)。何が起こるか確認できます。このセルだけでなく、同じ列にある他のセルや、その列の中にあるグリッドも自動的に再フォーマットされるはずです。なお、列幅は1行あたりの最大文字数を指定するものなので、すべてのセルが1行に収まった状態では、それ以上グリッドが広がることはありません。
        一部のMacキーボードでは、PageUp/PageDownはFN+上下キーで代用されます。また、マウスホイールの代わりにトラックパッド(またはMagic Mouse)のスワイプ操作を使います。

    画像とスタイル
      セルに画像を追加すると、ドキュメントをより分かりやすくできます。画像はそのセルのテキストの手前に表示されます。柔軟性を最大限に活かすには、画像専用のセルを用意するとよいでしょう。上のいずれかのセルに(小さな)画像を追加してみてください(Edit/Add Imageメニュー、またはツールバーの画像ドロップダウンから選択できます)。
        画像はドキュメント(.cts)ファイルの内部に保存されるため、ファイルを移動しても画像が失われることはありません。同じ画像をドキュメント内で複数回使用しても、保存されるのは1コピーだけです。
        大きな画像をtreesheetから参照したいけれど、シートの中に埋め込むと扱いにくい場合は、画像を.ctsファイルと同じフォルダに置き、セルにはその名前だけを入力するという方法もあります。その後Edit/Open File(F4)を使うことで、その画像を表示できます。
          この方法であれば、どんな種類のファイルでも参照できます
          新しいファイルへのリンクを手早く追加するには、画像以外のファイルをセルにドラッグ&ドロップするだけです
      セルを太字や斜体、あるいはその両方にすることができます!いくつかのセルでCTRL+bやCTRL+iを試してみてください。どちらもトグル(オン/オフ切り替え)です。さらに、等幅フォントや下線のスタイルもEdit/Text Styleメニューから利用できます。
      取り消し線(CTRL+t)は、処理済みだがまだ削除したくない項目を示すために、ToDoリストで役立つスタイルです。
      ツールバーにある2つのカラー選択ツールを使って、セルに色を付けてみましょう。現在の色をダブルクリックすると、即座にその色を設定できます。グリッドを含むセルを選択し、境界線色のドロップダウンやEdit/Set Border Widthメニューを使うと、見た目を変更できます。
      詳細、出典、備忘録など、セルのテキストを煩雑にしたくない情報は、ノートとしてセルに追加できます。セルを選択して CTRL+E を押します(編集(E) > ノートを編集(N))。ノートがあるセルには、右上の角に小さな三角形が表示されます。三角形にマウスを合わせるとノートが表示され、クリックするとノートを編集できます。このセルにはノートがあるので、試してみてください! 表示(V) > フィルター > ノートがあるセルを表示 で、ノートのあるセルをすべて見つけられます。
    検索とナビゲーション

    タグと階層構造
      タグは、ステータスやカテゴリなど、シート内で繰り返し使う単語を扱うのに便利な方法です。何かをタグにするには、その単語が出てくる箇所を見つけて"Add Cell as Tag"(Edit/Tag...メニュー)を実行します。以降は、CTRL+右クリック(ポップアップメニュー)で他の任意のセルをそのタグに設定できるようになります。タグは青色で表示され、タグであることが一目で分かります。これにより、タグの入力ミスにも気づきやすくなります。
      タグとの相性がよい強力な操作に"Hierarchy Swap(階層の入れ替え)"があります。その動作の例を見てみましょう:
        Hierarchy Swapが生まれた背景には、TreeSheetsでデータをツリー形式に整理する際、ツリー構造は必ずしもデータ整理に理想的とは限らない、という事情があります。というのも、ツリーではどの区分を最も重要にするかを決めなければならないからです。
        例えば、あるプロジェクトを整理していて、そこに含まれるタスクを管理しようとしているとします。担当者、成果物、トピック領域を示すためにタグを使っています:
          マイルストーン1
            フロントエンド
              フレッド
                GUIを修正する
                データベースに接続する
              ボブ
                グラフィックを一新する
            バックエンド
              フレッド
                入力フォームを追加する
          マイルストーン2
            バックエンド
              フレッド
                新しいテーブルをセットアップする
              ボブ
                新しいサーバーを購入する
                ネットワークをセットアップする
        上の表では、マイルストーンが最も重要な区分となり、トピック領域が2番目、担当者が最も重要度の低い区分になっていることに注目してください。これはかなり恣意的な選び方であり、担当者の視点から見たいこともあるでしょう。Hierarchy Swapを使えば、それが可能です!"フレッド"が出てくる箇所をどれか選択し、F8を2回押すと、次のようになります:

        実際にあなたが行ったのは、"この階層構造をフレッドの視点から見せて"と指示することです。これで彼が何に取り組んでいるかが正確にわかるようになりました。必要であればボブについても同じことができます。フレッドがバックエンドで何をしているか見たい場合は、(フレッドの中の)"バックエンド"でF8を1回だけ押してみてください。視点がさらに調整されます。もう一度押すと、今度はフロントエンド/バックエンドが主要な区分になります。
        さまざまなタグに対してF8を押し続けることで、必要な視点をどのように得られるか確認してみてください。
        重要なのは、入れ替えを行うたびに、それまで親だったタグが、選択したタグの子になるという点です。つまり、この入れ替えを何度行っても情報が失われることはありません。望めば元のツリー構成に戻せる、ということでもあります。
        つまりこの機能は、いくつでもタグを関連付けられる情報の断片を持てるようにするものだと考えることができます。Hierarchy Swapによってタグの重要度の現在の順序を決めることができ、そのためツリー表示は単に直近の視点を反映しているにすぎません
        どの"視点"になっていても、そのままツリーのデータを編集し続けることができ、元の順序に戻す必要はありません。このようなツリーには決まった順序というものがないのです!
        "フレッド"を昇格させても、"ボブ"が自動的に昇格するわけではないことに注目してください。TreeSheetsは、これらのタグが同じ"種類"であるとは認識していません。タグの使い方が必ずしも明確な種類に分かれているとは限らず、また一度にすべてを並べ替える必要があるとも限らないため、この機能はシンプルさを保っています。

      フィルターは、treesheetがかなり大きくなってきたときに便利な機能です。これを使うと、シートの一部を一時的にフィルタリングして除外し、探しているセルに焦点を当てることができます。この機能は、フィルタリングされて除外されたセルを1ピクセルの薄いグレーの文字として強制的に表示することで実現されています。Viewメニューにあるフィルタリングのオプションを試してみてください:
        今すぐ検索クエリとして"treesheets"と入力してみてください。いくつかのセルが赤く表示されるはずです。次に検索フィルターを設定してみましょう(View -> Filter -> Show only cells in current search)。シート全体がかなり縮小され、探しているものを見つけやすくなるはずです。これはこのシートの最上位レベルの表示で試してください。フィルターをオンにしたままズームイン・ズームアウトも試してみてください。検索クエリを編集すると、入力に応じてフィルター表示が変化します。
        このシートで"last 10% of edits(直近10%の編集)"も試してみてください。まず検索クエリをオフにしておいてください。なお、古いバージョンのtreesheetsで作成されたドキュメントの場合、当時のバージョンでは各セルの最終編集時刻をまだ記録していなかったため、この機能が期待通りの編集内容を表示しないことがあります。
      古いコンピューターを使っている場合や、非常に大きなシートを扱う場合は、"fast line rendering"オプションを試してみてください。見た目はやや劣りますが、スクロールが速くなります。
      TreeSheetsはプレゼンテーションにも最適です。聴衆に構造を伝えるのが難しい従来型のツール(PowerPointなど)とは異なり、treesheetをまるでプレゼンテーション全体が1枚の"スライド"であるかのように構成し、縮小されたサブスライドにズームインしていくことができます。プレゼンテーションツールとしての利用を助けるため、TreeSheetsには2つの表示オプションがあります。視覚的な雑然さを減らすフルスクリーン表示(F11)と、現在の表示をできる限り大きくしようとする拡大表示(F12)です。
        なお、この機能と印刷機能はどちらも、すべてのケースで描画の忠実さを保てるとは限らない拡大縮小方式を使用しています。これは将来のバージョンで修正される予定です。

      数式は表計算ソフトのように結果を計算し、何かを変更するたびに自動で更新されます。セルに = で始まるテキスト(例: =SUM(費用))を入力し、セルを離れると結果が表示されます。数式バー(ツールバーの「Formula」)には選択中のセルの数式が表示され、そこで編集することもできます(ENTERで適用)。

        SUM、MIN、MAX、AVG、MEDIAN、COUNTを、数値、+ - * / やかっこと組み合わせて使えます。例: =(SUM(収入) - SUM(費用)) / 12。名前のグリッドの直下にある数値だけが対象で、他の数式の結果も数値として扱われます。先頭にTREEを付けると（例: =TREESUM(費用)）、すべてのサブグリッドの数値も対象になりますが、そこにある数式は対象外です。名前だけを書くと、そのグリッドにある1つの数値を表します。例: =単価 * 数量。

        SUBSETだけを書くと、その中にある1つの数値を表します。例: =SUBSET(売上, 1, 2) * 2。名前は引用符で囲むこともでき、カンマやかっこを含む名前ではそれが必要です。例: =SUM("費用, 2025")、=MAX(SUBSET("売上 (EUR)", 0, -))。
        数式では、上で説明したプログラム言語の変数も使えます。どのグリッドの名前でもない名前は、その名前の変数を表し、値はプログラムを最後に実行したときに代入されたものです。グリッドを持つ変数はグリッドと同じように数えられます。例: =SUM(得点)。プログラム(P) > 実行(R) でプログラムを実行するまで、そのような数式は #N/A を表示します。下の左側のプログラムは 1 + 2 * 3 を計算し、その結果を変数「答え」に代入します(プログラム(P) > マーク(M) > 変数代入(A) でマークしてあります)。実行して、右側の結果を見てください:

        問題がある場合、セルにはエラーが表示されます: 不明な名前や関数は #NAME?、ゼロ除算は #DIV/0!、互いに依存する数式は #CYCLE!、名前やSUBSETだけで数値がちょうど1つではない場合は #VALUE!、プログラムを実行する前の変数は #N/A、読み取れない数式は #ERROR! です。
      テンプレートを使うと、週の予定やプロジェクトの骨組みなど、前に用意したドキュメントから新しいドキュメントを始められます。ファイル > テンプレートから新規作成 にあります:
        「現在のドキュメントをテンプレートとして追加」は、現在のドキュメントのファイルをこのメニューに追加します(先に保存してください)。「ファイルをテンプレートとして追加...」は、ほかのTreeSheetsファイルを追加します。
        そこでテンプレートをクリックすると、その内容のコピーを持つ新しい無題のドキュメントが作成されます。保存するときは新しいファイル名を尋ねられるので、テンプレートのファイル自体はそのまま残ります。
        「ファイルをテンプレートとして開く...」は、任意のTreeSheetsファイルでメニューに追加せずに同じことを行います。「テンプレートを削除...」はテンプレートをメニューから外します(ファイルはそのまま残ります)。
      複数のコンピューターでTreeSheetsのファイルを扱う場合は、それらを(DropBoxなどの)共有フォルダに保存し、Options -> Auto reload documentsをオンにしてください
        こうしておけば、ドキュメントを保存するたびに、すべてのマシンで常に最新の状態になります
      コマンドラインからTreeSheetsを実行する
        TreeSheetsはコマンドラインから実行することができます
        引数として、読み込む単一のファイルを指定できます
          TreeSheetsがすでにシステム上で実行されている場合、このファイルは既存のインスタンスに渡され、その後(新しく起動したプロセスは)終了します
        引数として-pを付けて実行することもできます
          これによりTreeSheetsが"ポータブル"モードで起動し、(Windowsの場合)設定がレジストリではなくカレントディレクトリの.iniファイルに書き込まれるようになります
        コマンドラインから正しく実行するには、少なくともWindowsでは、TreeSheets.exeをフルパスで起動する必要があることに注意してください。そうしないと、実行ファイルのパスを基準としたアイコンなどのファイルを見つけられなくなります。
