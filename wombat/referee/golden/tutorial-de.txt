   
  Willkommen bei TreeSheets!
  (1) Diese Datei ist eine Hands-On Einführung. Durch simples Abarbeiten der Schritte anhand der Numerierung vor den Texten, kann man alle TreeSheets Funktionen schnell und einfach lernen und üben!
    Die Grundlagen
      (2) Sie haben Schritt 2 gefunden! Gut, dann wollen wir mal Text einfügen. Jedes dieser Textfelder ist eine sogenannte „Zelle“. Sehen Sie die leere Zelle zwischen (2) und (3)? Klicken Sie irgendwo in sie hinein, um sie zu selektieren 
      
      (3) Die Zelle oberhalb sollte nun selektiert sein (mit einem dicken, schwarzen Rand drumherum). Nun tippen Sie irgendwas, und der geschriebene Text landet in der selektierten Zelle. Haben Sie bemerkt, daß ein ein Cursor erschienen ist, als Sie zu schreiben anfingen, und der Markierungskasten wurde dünner. Dies zeigt an, daß sich die Zelle im Texteingabemodus befindet, so daß Pfeiltasten, Entfernen-Taste usw. im aktuellen Text benutzt werden können. Man gelangt auch über einen Doppelklick in den Texteingabemodus, oder durch Drücken der Eingabetaste (Enter). Um diesen Modus zu beenden, entweder erneut die Eingabetaste drücken, die Escape-Taste drücken, oder einfach eine andere Zelle selektieren.
      (4) Es gibt sogar noch einen besseren Weg, um Text einzugeben. Sehen Sie die gepunkteten Linien zwischen den Zellen? Diese nennen wir „Rasterlinien“. Selektieren Sie (bzw. klicken Sie auf) die Rasterlinie zwischen (4) und (5).
      (5) Die Linie über hier sollte hervorgehoben sein. Fangen Sie jetzt an, etwas einzutippen, und Sie bemerken, daß automatisch eine neue Zelle zwischen (4) und (5) eingefügt wurde. Das funktioniert auch mit den seitlichen Linien. Dies ist der natürliche Weg, ein TreeSheet zu erweitern: Suchen/Markieren Sie eine Stelle, an der Informationen hinzugefügt werden sollen und tippen Sie einfach los!
      (6) Für ein noch schnelleres Bearbeiten könen Sie sich auch ohne Maus innerhalb von Zellen und Rasterlinien bewegen: Aktivieren Sie diese Zelle und betätigen Sie dann ein paar mal die Pfeiltasten hoch/runter.
      (7) Das Löschen von Zellen funktioniert auf die gleiche Weise. Markieren Sie irgendeine Rasterlinie oberhalb und drücken Sie dann die Rücktaste (Backspace), um die Zelle darüber  (oder davor) zu löschen, oder drücken Sie ENTF um die Zelle darunter (oder danach) zu entfernen. Auf diese Weise funktionieren auch Editoren und Textverarbeitungen. Alternativ kann auch jede Zelle (oder mehrere Zellen) durch Klicken/Markieren selektiert und mittels der Taste ENTF gelöscht werden.
      (8) Wenn Sie einige Zeilen oberhalb gelöscht haben  (hoffentlich nicht diese!), wäre jetzt eine gute Gelegenheit, die Funktion "Rückgängig" auszuprobieren! Drücken Sie mehrmals STRG+Z, um die gelöschten Zellen wiederherzustellen. TreeSheets verfügt über unbegrenztes Rückgängig, dauerhaftes festhalten von STRG+Z stellt also das Original-Dokument wieder her. STRG+Y wiederholt Vorgänge.
        In OS X, verwenden Sie statt STRG die Taste CMD. ALT entspricht der Taste OPTION.

      (11) Versuchen Sie die eben (10) erstellte Zelle zu erweitern, indem Sie eine der 4 Rasterlinien markieren und Text eingeben, bis Sie eine 3x3 Tabelle haben. Versuchen Sie auch, sich mit den Pfeiltasten in alle Richtungen darin zu bewegen.
      (12) Lassen Sie uns jetzt versuchen, Dinge innerhalb von Tabellen zu bewegen. Selektieren Sie eine ganze Spalte einer Tabelle (wie z.B. die Zahlen der Tabelle in (9)) durch Klicken und Ziehen von Oben nach Unten. So wie in Tabellenkalkulationen (und nicht wie in einigen anderen Programmen), dient das Ziehen in TreeSheets zur Erweiterung einer Auswahl, nicht zum Bewegen. Drücken Sie nun STRG+PfeilLinks oder STRG+PfeilRechts um die Daten zu bewegen.
      (13) Sie können Zellen kopieren, selektieren Sie beispielsweise diese hier, kopieren Sie diese mit STRG+C, dann selektieren Sie eine beliebige Rasterlinie oberhalb und drücken STRG+V. Wenn Sie mehrere Zellen selektieren, wird die Auswahl als mehrfache Zeilen im Zielbereich eingefügt. Versuchen Sie es. Ausschneiden (STRG+X) oder Löschen mehrerer Zellen funktioniert ähnlich intuitiv. Falls das „Inline“-Einfügen nicht gewünscht ist, können Sie jederzeit zuerst eine neue Zelle erstellen und dann in dieser einfügen, um eine Hierarchie zu erzeugen.
    Zellformatierung & Zoom
      (14) Text in einer Zelle ist so ähnlich wie ein einzelner Absatz. Er wird automatisch umbrochen, je nach Größe der Zelle, in der er steht. Wie breit die Spalten sein sollen, hängt von Ihren Vorstellungen zur Struktur Ihres TreeSheets ab. Sie können die Spaltenbreite in der Statusanzeige sehen (für die Spalte, über der die Maus steht). Stellen Sie sicher, daß diese Zelle selektiert ist, und halten Sie dann ALT und betätigen Sie das Mausrad um zu sehen, was passiert (oder ALT+BildAuf/BildAb). Diese Zelle sollte automatisch neu formatiert werden, genau wie andere Zellen dieser Spalte und aller Tabellen dieser Spalte. Beachten Sie, daß die Spaltenbreite die maximale Anzahl an Zeichen pro Zeile darstellt, so daß die Tabelle nicht breiter wird, wenn jede Zelle irgendwann in einer einzigen Zeile steht.
        Bei einigen Mac-Tastaturen werden die Tasten BildAuf/BildAb durch FN+Hoch/Runter emuliert. Ausserdem ersetzt ein Wischen auf dem Trackpad das Mausrad (oder der Magic Mouse).
      (15) Eine mächtigere Möglichkeit, den Platz, den eine Zelle auf dem Bildschirm einnimmt, zu verändern (gut zum Herausstellen von relativen Gewichtungen), ist das Ändern der Schriftgröße. Selektieren Sie diese Zelle, halten Sie SHIFT und betätigen Sie das Mausrad (oder SHIFT+BildAuf/BildAb).
      (16) Beachten Sie, daß Text als individuelle Pixel dargestellt wird, wenn Sie ihn verkleinern. Dies mag unnötig erscheinen, stellt aber eine praktische Art des Informationsmanagements dar, die das häufig verwendete Zusammenklappen/Aufklappen von Hierarchien in anderen Programmen ersetzt.
      (17) Diese Zelle enthält eine winzige Tabelle. Selektieren Sie diese Zelle, dann halten Sie STRG und drehen Sie das Mausrad 3x vorwärts um in diese Zelle hineinzuzoomen (oder STRG+BildAuf/BildAb).
        (18) Sie konnten diesen Text vorher nicht lesen, aber jetzt können Sie es!
        (19) Wenn Sie hineinzoomen, setzt TreeSheets die Schriftgröße auf die durchschnittliche Größe der darüberliegenden Tabelle. Wenn Sie die Schriftgröße mittels SHIFT+sMausrad verändern, ändern Sie die relative Textgröße. Das bedeutet, es hängt von der Zoomstufe ab, wie groß der Text erscheint. Das hört sich kompliziert an, hat aber den Effekt, daß (viel) Text sehr klein gehalten, aber durch Hineinzoomen gelesen werden kann.
        (20) Die Idee dahinter ist, daß Sie kleine Untertabellen wie diese hier nutzen, um Informationen vorzuhalten (wie z.B. eine Todo-Liste für ein bestimmtes Projekt), die zwar im TreeSheet enthalten sein, jedoch möglichst wenig Platz einnehmen sollen. Lesen oder bearbeiten ist dann immer nur eine Mausradumdrehung weit weg.
        (21) Ausserdem ist das Festlegen der Schriftgröße normalerweise etwas, was Sie nur einmal machen müssen, wohingegen das Ein- und Ausklappen von Hierarchien und das Scrollen zu gewünschten Informationen in anderen Anwendungen ständig vorkommt. TreeSheets macht das Navigieren durch große Informationsmengen wesentlich angenehmer und einfacher zu überblicken (der pixelgroße Text gibt immernoch einen Eindruck davon, wieviele Informationen in der Zelle stecken, und von deren Struktur).
        (22) Um diesen Text wieder auf der übergeordneten Ebene lesbar zu machen, selektieren Sie die Zellen (18-23) (nicht 17), zoomen zweimal heraus (Mausrad rückwärts), und dann SHIFT+Mausrad vorwärts bis dies wieder lesbar wird.
        (23) Wenn Sie nun wünschen, dies zu verkleinern, selektieren Sie die selben Zellen und verwenden SHIFT+Mausrad rückwärts um die Größe zu verkleinern.
        (24) Bemerken Sie den grauen Text, welcher sich über der Kopfzeile befindet, wenn Sie hineingezoomed haben? Dieser wird Kontext genannt und hilft Ihnen zu wissen, in welchen Teil Ihres TreeSheets Sie hineingezoomt haben.
      Falls Sie es wünschen, eine Tabelle komplett aus dem Sichtfeld zu nehmen, verwenden Sie „folding“ (F10 in Windows, STRG+F10 auf anderen Plattformen). Versuchen Sie es mehrmals auf dieser Zelle, um diesen Effekt zu sehen
        Diese Zelle und die unterhalb werden versteckt!
        Beachten Sie, daß eine Zelle mit einer versteckten Tabelle darin ein „+“-Symbol erhält, welches anzeigt, daß hier weitere Informationen angezeigt werden können. Wenn Sie diese aufklappen, verschwindet das Symbol automatisch.
        Zellen werden ebenfalls automatisch aufgeklappt, wenn Sie Funktionen wie „search next“ verwenden, um zwischen Zellen zu springen, welche gerade nicht sichtbar sind.
        Obwohl Zusammenklappen eine Funktion ist, die Ihnen aus anderen Anwendungen bekannt sein könnte, bietet Ihnen das Verkleinern von Text (siehe 17) eine bessere Übersicht über Ihre Informationen. Probieren Sie's aus!

    Bilder & Stile
      Fügen Sie Bilder in Zellen ein, um Ihr Dokument klarer zu gestalten. Bilder erscheinen vor dem Text der Zelle. Fügen Sie ein Bild in seine eigene Zelle ein, um maximale Flexibilität zu erhalten. Versuchen Sie ein (kleines) Bild in eine beliebige Zelle oberhalb einzufügen (Menü Bearbeiten/Bilder.../Bild hinzufügen, oder wählen Sie eines aus dem Bilder-Dropdown in der Symbolleiste). 
        Bilder werden innerhalb des Dokumentes gespeichert (.cts Datei), was bedeutet, daß das Bild im Dokument erhalten bleibt, wenn Sie es verschieben sollten. Wird ein Bild mehrfach im Dokument verwendet, wird lediglich eine Kopie gespeichert.
        Wenn Sie innerhalb eines TreeSheets größere Bilder verwenden wollen, diese jedoch zu unpraktisch innerhalb des Dokuments zu speichern wären, können Sie diese einfach in das Verzeichnis kopieren, in dem sich die .cts Datei befindet, und einfach deren Namen in die Zellen schreiben. Dann können Sie Edit/Open File (F4) nutzen, um diese anzuzeigen.
          Sie können jeden Dateityp auf diese Weise referenzieren.
          Um neue Dateiverweise bequem einzufügen, ziehen Sie einfach Dateien, die keine Bilder sind, per Drag+Drop auf die gewünschten Zellen.
      Formatieren Sie eine Zelle fett, kursiv oder beides! Versuchen Sie STRG+B oder STRG+I auf einigen Zellen; beides setzt/deaktiviert. Zusätzlich sind die Stile Schreibmaschine und Unterstrichen über das Menü Bearbeiten/Textstil... verfügbar.
      Durchgestrichen (STRG+L) ist ein nützlicher Stil für ToDo-Listen, um abgearbeitete Aufgaben anzuzeigen, die man jedoch noch nicht löschen möchte.
      Versuchen Sie mal, Zellen mittels der beiden Farbwahl-Dropdowns in der Symbolleiste einzufärben. Sie können die aktuelle Farbe per Doppelklick sofort setzen. Selektieren Sie Zellen, die Tabellen enthalten, und verwenden Sie das Rahmenfarben-Dropdown oder das Menü Bearbeiten/Breite des Tabellenrands setzen..., um deren Aussehen zu verändern.
      Fügen Sie einer Zelle eine Notiz hinzu für alles, was ihren Text nicht überladen soll, etwa Einzelheiten, Quellen oder Erinnerungen: Wählen Sie die Zelle aus und drücken Sie STRG+E (Bearbeiten > Notiz bearbeiten). Eine Zelle mit Notiz zeigt ein kleines Dreieck in ihrer oberen rechten Ecke. Zeigen Sie auf das Dreieck, um die Notiz zu lesen, und klicken Sie darauf, um sie zu bearbeiten. Diese Zelle hat eine Notiz, probieren Sie es aus! Mit Ansicht > Filter > Zellen mit Notizen anzeigen finden Sie alle.

    Tags & Hierarchie
      Tags sind eine gute Methode um mit Begriffen umzugehen, welche Sie wiederholt in einem Dokument verwenden, beispielsweise Status, Kategorien, usw. Um etwas als Tag zu definieren, suchen Sie ein Vorkommen und verwenden Sie "Add Cell as Tag" (Menü Edit/Tag...). Von da an können Sie jede andere Zelle mit STRG+Rechtsklick als Tag setzen. Tags werden blau dargestellt. Dies hilft, falls ein Tag falsch geschrieben ist.
      Eine mächtige Methode, die sehr gut mit Tags funktioniert ist  "Hierarchietausch". Hier ein Beispiel, wie das praktisch angewendet werden kann:
        Die Motivation hinter Hierarchietausch ist, daß Sie TreeSheets dazu verwenden, Daten in einer Baumstruktur zu verwalten, dies für Daten  jedoch oft nicht ideal ist, weil es Sie das dazu zwingt festzulegen, welche Untergruppierung am wichtigsten ist. 
        Nehmen wir an, Sie verwalten ein Projekt und wollen festhalten, welche Aufgaben es beinhaltet. Sie verwenden Tags, um die Kollegen, die daran mitarbeiten, die zu erledigenden Aufgaben und die Arbeitsbereiche anzuzeigen:

Dies ist eine recht willkürliche Sicht, und eventuell wollen Sie die Dinge aus der Mitarbeiter-Perspektive betrachten, was sich mit Hierarchietausch bewerkstelligen lässt!         WIchtig zu wissen ist, daß bei jedem Hierarchietausch das vormalige Eltern-Tag des ausgewählten Tags zum Kind-Tag wird. Das bedeutet, daß es keine Rolle spielt, wie oft Sie den Hierarchietausch durchführen, es geht keinerlei Information verloren. Sie können die Ursprungsstruktur wieder erreichen, wenn Sie dies wünschen.
        Sie können dieses Feature als Möglichkeite betrachten, Informationsstückchen mit beliebiger Zahl von Tags zu verknüpfen. Der Hierarchietausch ermöglicht Ihnen, die Wichtigkeitsreihenfolge von Tags festzulegen. Dadurch ist die Baumansicht lediglich die zuletzt gewählte Ansicht.
        Sie können die Daten im Baum wieterhin bearbeiten, ganz gleich, in welcher „Ansicht“ er sich befindet. Sie müssen den Baum nicht in die Ursprungsreihenfolge zurückversetzen. Bäume haben keine feste Ordnung!
        Beachten Sie, daß „Michael“ höherzustufen nicht automatisch auch „Edi“ höherstuft. TreeSheets weiß nicht, daß diese Tags vom gleichen „Typ“ sind. Nicht alle verwendeten Tags haben klar abgegrenzte Typen und es ist nicht immer notwendig, alle gleichzeitig neu anzuordnen. Dies hält die Funktion einfach.

      Filter sind nützlich, wenn Ihre TreeSheets irgendwann wirklich groß werden. Diese erlauben Ihnen, eine temporäre, gefilterte Sicht auf die Zellen, die gesucht werden. Dies wird dadurch erreicht, daß die ausgefilterten Zellen als 1-Pixel Text in Hellgrau dargestellt werden. Probieren Sie die Filterfunktion im Menü View aus:
        Tippen Sie „treesheets“ als Suchbegriff gleich ein. Einige Zellen werden rot angezeigt. Setzen Sie jetzt den Suchfilter (Ansicht/Filter.../Nur Zellen in der aktuellen Suche anzeigen), alle Sheets sollten merklich schrumpfen, was es einfacher macht, das zu sehen, was man sucht. Machen Sie das auf der obersten Ansichtsebene dieses Sheets. Zoomen Sie mit aktiviertem Filter rein und raus. Bearbeiten Sie den Suchbegriff, die Filteransicht verändert sich schon während der Eingabe.
        Probieren Sie auch die Einstellung „10% der letzten Änderungen anzeigen“ mit diesem Sheet. Deaktivieren Sie vorher die Filterung. Beachten Sie, daß bei  älteren TreeSheet-Dokumenten diese Funktion nicht zu 100% funktioniert, da ältere Versionen die Bearbeitungszeit der Zellen noch nicht gespeichert haben.
      Wenn Sie einen älteren PC verwenden, oder sehr große TreeSheets bearbeiten, probieren Sie die Funktion „Schnelleres Zeilen-Rendering“, um das Dokument weniger „schön“, dafür aber schneller scrollbar zu machen.
      TreeSheets eignet sich sehr gut für Präsentationen. Anders als traditionelle Werkzeuge wie Powerpoint, die es sehr schwer machen, dem Publikum eine Struktur darzustellen, können TreeSheets als eine große „Folie“ organisiert werden, mit minimierten Unterfolien, in die bei Bedarf hineingezoomt werden kann. Um es als Präsentationswerkzeug zu verwenden, gibt es zwei Betrachtungsmodi: Vollbild (F11) zur Minimierung optischer Ablenkungen, und Skalierte Präsentationsansicht (F12), welche versucht, die aktuelle Ansicht so groß wie möglich darzustellen.
        Beachten Sie, daß diese beiden Funktionen und das Drucken sich einer Skaliermethode bedienen, welche die Darstellungstreue nicht in allen Fällen erhält. Dies wird in einer späteren Version korrigiert werden.
      TreeSheets beinhaltet eine neue, tabellenkalkulationsartige Programmiersprache, welche momentan noch nicht voll funktionstüchtig ist.
        Dies funktioniert durch Einfügen von Operationen direkt in Tabellen, gemischt mit Daten.
        Die Sprache interpretiert dann die Tabellenausdrücke von links nach rechts (und oben nach unten), wenn Sie das Dokument „laufen“ lassen. Wählen Sie Program/Run (oder das Symbol in der Symbolleiste) und die grüne Zelle unten sollte mit einer 9 gefüllt werden 
          1
          +
          2
          *
          3
          
        Sie erzeugen ein Programm, indem Sie bestimmten Zellen eine Funktion zuweisen. Standardmäßig sind alle Zellen weiß (Daten). Aus dem Menü Programm/Markieren als können Sie diese  als Operationen (rosa) oder Ergebniszellen (Hellgrün) deklarieren. Eine Ergebniszelle zeigt einfach den aktuellen Wert der vorangestellten Operationen an. Versuchen Sie über das Programm-Menü in der Tabelle unten das + als Operation und die letzte Zelle als horizontale Ergebniszelle zu deklarieren. Dann klicken Sie run:
          1
          +
          2
          
        Operationen funktionieren automatisch innerhalb der gesamten Tabelle, beispielsweise:

      Formeln berechnen Ergebnisse wie in einer Tabellenkalkulation und aktualisieren sich von selbst, sobald Sie etwas ändern. Geben Sie in eine Zelle einen Text ein, der mit = beginnt, etwa =SUM(Kosten). Sobald Sie die Zelle verlassen, zeigt sie das Ergebnis. Die Formelleiste („Formel“ in der Symbolleiste) zeigt die Formel der selektierten Zelle, und Sie können sie dort auch bearbeiten (ENTER übernimmt sie).

        Sie können SUM, MIN, MAX, AVG, MEDIAN und COUNT verwenden, zusammen mit Zahlen, + - * / und Klammern, z. B. =(SUM(Einnahmen) - SUM(Kosten)) / 12. Es zählen nur die Zahlen direkt in der benannten Tabelle, und auch die Ergebnisse anderer Formeln zählen als Zahlen. Mit TREE davor, z. B. =TREESUM(Kosten), zählen auch die Zahlen in allen untergeordneten Tabellen, aber nicht die Formeln dort. Ein Name allein steht für die eine Zahl in seiner Tabelle, z. B. =Preis * Menge.

        Wenn etwas nicht stimmt, zeigt die Zelle einen Fehler: #NAME? für einen unbekannten Namen oder eine unbekannte Funktion, #DIV/0! für eine Division durch null, #CYCLE! für Formeln, die voneinander abhängen, #VALUE! für einen Namen oder ein SUBSET allein, in dem nicht genau eine Zahl steht, #N/A für eine Variable, bevor das Programm ausgeführt wurde, und #ERROR! für eine Formel, die nicht gelesen werden kann.
      Vorlagen beginnen neue Dokumente mit einem, das Sie schon vorbereitet haben, etwa einem Wochenplan oder einer Projektgliederung. Sie finden sie unter Datei > Neu aus Vorlage:
        Aktuelles Dokument als Vorlage hinzufügen fügt die Datei des aktuellen Dokuments zu diesem Menü hinzu (speichern Sie es zuerst), und Dateien als Vorlagen hinzufügen... fügt andere TreeSheets-Dateien hinzu.
        Ein Klick auf eine Vorlage dort erstellt ein neues, unbenanntes Dokument mit einer Kopie ihres Inhalts. Die Vorlagendatei selbst bleibt unverändert, denn beim Speichern wird nach einem neuen Dateinamen gefragt.
        Datei als Vorlage öffnen... macht dasselbe mit einer beliebigen TreeSheets-Datei, ohne sie zum Menü hinzuzufügen, und Vorlage entfernen... nimmt eine Vorlage wieder aus dem Menü (die Datei bleibt, wo sie ist).
      Wenn Sie auf verschiedenen PCs mit TreeSheets Dateien arbeiten, speichern Sie diese in einem gemeinsamen Verzeichnis (wie z.B. DropBox) und aktivieren Sie im Menü Optionen/Dokument automatisch neu laden.
        Auf diese Weise haben Sie nach dem Speichern auf allen PCs immer ein aktuelles Dokument zur Verfügung
      Starten von TreeSheets von der Kommandozeile aus
        TreeSheets kann von der Kommandozeile aus gestartet werden.
        Sie können eine Datei als Argument übergeben.
          Sollte TreeSheets bereits laufen, wird diese Datei der laufenden Instanz übergeben und die neue dann beendet.
        Sie können auch den Parameter -p verwenden.
          Dies startet TreeSheets im „portablen“ Modus, in dem (unter Windows) die Einstellungen in einer .ini Datei innerhalb des aktuellen Verzeichnisses statt der Registry gespeichert werden.
        Beachten Sie, daß für eine korrekte Ausführung von der Befehlszeile aus (zumindest unter Windows) TreeSheets.exe mit dem vollständigen Pfad aufgerufen werden muß. Ansonsten können die Icons usw. zum relativen Pfad nicht gefunden werden.
